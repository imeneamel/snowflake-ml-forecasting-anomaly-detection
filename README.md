# Snowflake ML Forecasting vs Prophet

Comparaison entre les capacités natives de prévision de séries temporelles de Snowflake ML Functions et le modèle open-source Prophet.

## Objectifs

- Explorer Snowflake Forecasting
- Évaluer les performances de Prophet sur le même dataset
- Comparer simplicité d'utilisation, interprétabilité et qualité des prévisions
- Étudier l'apport de variables métier (jours fériés)
